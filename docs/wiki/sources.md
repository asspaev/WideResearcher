# Источники и цитаты

WideResearcher не просто собирает текст — он фиксирует, откуда взят каждый факт. Это решает главную проблему существующих AI-решений: непрозрачность источников.

## Как устроены источники

Результат исследования разбит на **сегменты**. К каждому сегменту в режиме Normal прикреплены:
- **Цитаты** — маркеры вида `[[1]]`, `[[2]]` внутри текста
- **Список источников** — URL страниц, которые использовались при написании этого сегмента

Цифра в маркере `[[N]]` соответствует номеру источника в списке под сегментом.

## Как появляются цитаты

1. **Chunking** — скрапленные страницы нарезаются на чанки по `max_tokens`
2. **Scoring** — чанки ранжируются через BM25 → Embed → Rerank
3. **Summarize** — LLM суммаризирует топ-N чанков, присваивая каждому порядковый номер
4. **Write** — LLM получает суммари с пронумерованными источниками и расставляет маркеры `[N]` в тексте
5. **apply_citations** — маркеры заменяются на кликабельные ссылки `[[N]](url)`

Маркер в тексте означает: **этот факт подтверждён цитатой из источника N**.

## Как читать источники

- Кликните на `[[N]]` — откроется оригинальная страница в новой вкладке
- Цифра соответствует порядку в списке источников под сегментом
- Один источник может цитироваться несколько раз в одном сегменте

## Как оценить качество источников

Смотрите на:

| Признак | Хороший | Плохой |
|---------|---------|--------|
| **Домен** | Академические (.edu, arxiv.org), Wikipedia, официальные сайты | Анонимные блоги, форумы |
| **Дата** | Соответствует периоду запроса | Устаревший контент |
| **Совпадение** | Страница действительно о теме запроса | Косвенное упоминание |

> Если маркер `[N]` отображается без ссылки — источник не был распознан при парсинге. Это редкость и означает, что LLM использовал этот номер в тексте, но соответствующего URL в наборе не оказалось.

## Ограничения

- WideResearcher не может получить контент с сайтов, защищённых Cloudflare или требующих авторизации
- PDF-файлы и медиаконтент не скрапятся
- Если страница недоступна в момент исследования — она пропускается, цитаты из неё не появятся

## Проверка источника вручную

Если вы сомневаетесь в факте из сегмента:
1. Найдите маркер `[[N]]` рядом с утверждением
2. Кликните — откроется исходная страница
3. Используйте поиск по странице (Ctrl+F) для нахождения конкретной фразы
