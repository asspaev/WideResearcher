# Модели

WideResearcher работает с любым провайдером, совместимым с OpenAI API. Модели настраиваются в разделе **«Модели»** — без правки конфигурационных файлов.

## Типы моделей

| Тип | Назначение |
|-----|-----------|
| **Генеративная** | Анализ, резюмирование, финальный текст. Используется в шагах direction, keywords, summarize, write, rename |
| **Эмбеддинг** | Векторное сходство для ранжирования чанков (scoring_embed) |
| **Reranker** | LLM оценивает релевантность чанков в диапазоне [0..1] (scoring_rerank) |

Для базовой работы достаточно только **генеративной** модели. Эмбеддинг и reranker подключаются опционально — они улучшают качество отбора источников.

## Поля при создании модели

| Поле | Обязательное | Описание |
|------|-------------|----------|
| **Название** | Да | Произвольное имя для отображения в UI (3–120 символов) |
| **Тип** | Да | generative / embedding / reranker |
| **Base URL** | Да | URL OpenAI-совместимого API (например `https://api.openai.com/v1`) |
| **Model API** | Да | Идентификатор модели у провайдера (например `gpt-4o`, `llama3.1:8b`) |
| **API Key** | Нет | Ключ авторизации; оставьте пустым для локальных провайдеров |
| **Max tokens** | Да | Максимальный контекст модели в токенах — влияет на размер чанков при нарезке |

## Совместимые провайдеры

| Провайдер | Base URL | Примечания |
|-----------|----------|-----------|
| OpenAI | `https://api.openai.com/v1` | Требует API Key |
| Ollama | `http://localhost:11434/v1` | Локально, без ключа |
| vLLM | `http://localhost:8000/v1` | Высокая производительность |
| LM Studio | `http://localhost:1234/v1` | Локально, без ключа |
| Mistral AI | `https://api.mistral.ai/v1` | Требует API Key |
| Together AI | `https://api.together.xyz/v1` | Требует API Key |
| Любой OpenAI-compatible | — | Укажите Base URL вашего провайдера |

## Как добавить модель

1. Перейдите в **«Модели»** → **«Новая модель»**
2. Выберите тип (generative / embedding / reranker)
3. Заполните Base URL и Model API согласно документации вашего провайдера
4. Укажите Max tokens: для GPT-4o это `128000`, для Llama 3.1 8B — `8192`
5. Нажмите **«Сохранить»**

После сохранения модель сразу доступна при создании нового исследования.

## Рекомендуемая конфигурация

- **Минимум:** 1 генеративная модель (шаги answer + search + direction)
- **Лучше:** генеративная + эмбеддинг — улучшает точность отбора источников на ~20%
- **Максимум:** генеративная + эмбеддинг + reranker — наиболее точный отбор, но медленнее

> Отдельные модели для шагов `answer`, `search` и `direction` выбираются в настройках каждого исследования. Это позволяет, например, использовать быструю модель для генерации ключевых слов и мощную — для финального текста.
