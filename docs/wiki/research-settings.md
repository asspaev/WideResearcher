# Настройки исследования

Все параметры задаются в попапе **«Настройки»** при создании исследования. Каждый параметр снабжён подсказкой (кнопка «?»).

## Сценарий

| Сценарий | Когда выбирать | Формат результата |
|----------|---------------|------------------|
| **Normal** | Исследование темы, аналитика, обзор | Развёрнутый текст с разделами |
| **Question** | Конкретный вопрос, нужен краткий ответ | 1–3 абзаца |

> **Normal** подходит для большинства случаев. **Question** оптимален когда нужен ответ на узкий вопрос вроде «Когда вышла версия X?» или «Сколько стоит Y?».

## Выбор моделей

| Поле | Используется в шаге | Если не задано |
|------|---------------------|----------------|
| **Модель (ответ)** | summarize, write, rename | Обязательно |
| **Модель (поиск)** | keywords | Обязательно |
| **Модель (направления)** | direction | Используется «Модель (ответ)» |
| **Модель (эмбеддинг)** | scoring_embed | Шаг пропускается |
| **Модель (reranker)** | scoring_rerank | Шаг пропускается |

## Параметры поиска

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| **Векторов направлений** | 5 | Сколько «углов зрения» на тему генерирует LLM. Больше → шире охват, медленнее |
| **Поисковых запросов** | 5 | Количество запросов в SearXNG на каждое направление |
| **Результатов поиска** | 10 | Максимум страниц из SearXNG на один запрос |
| **Параллельный парсинг** | 3 | Сколько страниц скрапится одновременно |
| **Домены для поиска** | — | Ограничить поиск конкретными сайтами (например `wikipedia.org, arxiv.org`) |
| **Исключить домены** | — | Запретить определённые сайты |

## Параметры скоринга чанков

После скрапинга текст разбивается на чанки и проходит три уровня фильтрации:

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| **Топ BM25** | 50 | Сколько чанков оставить после TF-IDF фильтрации |
| **Топ Embed** | 30 | Сколько чанков оставить после фильтрации по эмбеддингам |
| **Топ Rerank** | 15 | Сколько чанков оставить после reranker |
| **Топ чанков** | 15 | Итоговое число чанков, которые идут в summarize |

Воронка: все чанки → BM25 топ-50 → Embed топ-30 → Rerank топ-15 → Summarize.

> Уменьшение **«Топ чанков»** ускоряет исследование, но может снизить охват. Для детального анализа увеличьте до 25–30.

## Как настройки сохраняются

Настройки, выбранные при создании, сохраняются в Redis до запуска и записываются в `Research` при создании записи. При следующем запуске исследования (кнопка «Продолжить») настройки наследуются, но их можно изменить в попапе.
