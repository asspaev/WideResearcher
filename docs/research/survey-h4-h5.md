# Опрос для проверки гипотез H4 и H5

## Назначение

Один опрос, из которого извлекаются метрики и критерии приёмки для двух гипотез:

| Гипотеза | Утверждение | Что измеряем |
|---|---|---|
| **H4** | Посегментная привязка цитат → доверие к ответу +1.0 по Лайкерту | Сравнение `trust@B − trust@A` |
| **H5** | Feedback-aware версионирование → качество ответа +1.0 по Лайкерту | Сравнение `quality@C − quality@B` |

**Дизайн:** within-subjects, A → B → C. Каждый респондент видит **три варианта одного и того же ответа** на одинаковый исследовательский запрос и оценивает их по одной шкале. Порядок A → B → C фиксирован, потому что C логически содержит B, а B содержит A.

**Целевая выборка:** 30+ респондентов из ЦА (исследователи / аналитики / студенты, регулярно использующие deep-research-инструменты или LLM-чаты для рабочих/учебных задач).

## Часть 1. Исследовательский запрос (одинаков для всех вариантов)

> **Запрос:** «Какие современные подходы используются для борьбы с галлюцинациями больших языковых моделей? Какие из них подтверждены экспериментами в 2024–2025?»

Респонденту показываются **три варианта ответа** одной и той же системы на этот запрос. Содержательно тезисы во всех трёх вариантах идентичны — различается только форма подачи источников и наличие истории правок.

## Часть 6. Метрики и критерии приёмки

### 6.1. Извлекаемые показатели (на одного респондента)

| Показатель | Из вопроса | Используется в |
|---|---|---|
| `trust@A`, `trust@B`, `trust@C` | Q1 каждого варианта | H4 (основной), H5 (контроль) |
| `verifiability@A/B/C` | Q2 | H4 (вспомогательный) |
| `quality@A/B/C` | Q3 | H5 (основной) |
| `usability@A/B/C` | Q4 | H4 + H5 (вспомогательный) |
| `Δtrust(B−A)` | Q1.B − Q1.A | **H4** |
| `Δquality(C−B)` | Q3.C − Q3.B | **H5** |

### 6.2. Критерии приёмки

**H4 (доверие +1.0 от посегментной привязки):** считается подтверждённой, если

```
mean(Δtrust(B−A)) ≥ 1.0   и   p < 0.05 (парный t-test или Wilcoxon, H0: Δ = 0)
```

**H5 (качество +1.0 от feedback-aware версионирования):** считается подтверждённой, если

```
mean(Δquality(C−B)) ≥ 1.0   и   p < 0.05 (парный t-test или Wilcoxon)
```

> Важно: H5 сравнивает C **с B**, а не с A — иначе эффект H4 «протёк» бы в H5 и завысил его. Так оба эффекта изолированы.

### 6.3. Вспомогательные срезы для ВКР

- Средние и std по `trust / verifiability / quality / usability` × {A, B, C} — общая таблица в приложении.
- Корреляция между опытом респондента (Q0.3) и величиной Δ — даёт ли посегментная привязка больший эффект тем, кто уже пользовался deep-research.
- Распределение Q6 (ранжирование) — простая невзвешенная проверка предпочтений.
- Сводка свободных ответов Q5.B / Q5.C / Q7 — качественная часть для раздела обсуждения.

## Часть 7. Технические замечания к проведению

- Опрос распространяется через Google Forms / Yandex Forms; макеты вариантов A/B/C — статические HTML-страницы или скриншоты, ссылки в самой форме.
- Все 4 шкальных вопроса на каждый вариант обязательны; открытые Q5 — опциональны.
- Респондент **не знает**, какая гипотеза проверяется (формулировка во введении нейтральная: «исследование удобства интерфейсов глубокого поиска»).
- Не показывать варианты в случайном порядке: дизайн нарастающий (A ⊂ B ⊂ C по фичам). Случайный порядок ломал бы интерпретацию Δ.
- Минимум 30 валидных ответов; в идеале 50+.
