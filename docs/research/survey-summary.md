## Замечания к методике

- **Размер выборки.** n = 33 — выше минимального порога 30, заявленного в `survey-h4-h5.md`. Целевая аудитория («исследователи / аналитики / студенты с регулярным использованием LLM-чатов») представлена полностью; ни один респондент не отфильтрован скринингом Q0.2.
- **Тест.** Wilcoxon signed-rank использован как непараметрическая альтернатива t-тесту, поскольку Лайкерт-шкала формально ординальна. P-value считается через нормальную аппроксимацию с tie-correction и continuity correction (валидно для n ≥ 20).
- **Парный дизайн.** Каждый респондент видит все три варианта в фиксированном порядке A → B → C, поэтому дельты считаются внутри одного человека — между-субъектный разброс не влияет на оценку эффекта.
- **p-value для t-test.** Значение `0.0` в JSON означает, что хвост двустороннего теста ниже точности `float64` (≈ 5 · 10⁻³²⁴). Используется нормальная аппроксимация t-распределения — для df = 32 расхождение с точной t-распределением < 0.001 в районе порога 0.05.
